Une extension d'authentification par clé API pour le `Django REST Framework
<http://www.django-rest-framework.org/>`__.

-------------------------------------------------------------------------------

Django REST Simple API Key est un package construit sur Django, Django REST Framework, et le module de cryptographie fernet pour générer, chiffrer et déchiffrer des clés API.

Remerciements
-------------

Ce projet emprunte du code au `Django REST Framework
<https://github.com/encode/django-rest-framework/>`__ ainsi que des concepts
provenant d'une autre bibliothèque de clés API pour le Django REST
Framework, `djangorestframework-api-key
<https://github.com/florimondmanca/djangorestframework-api-key>`__.
